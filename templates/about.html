About the project

Automated Screening of Nail-Associated Melanoma Using the K-Nearest Neighbors (KNN) Algorithm

{% macro block(title) %}
{{ title }}
{{ caller() }}
{% endmacro %} {% call block('Problem statement') %} Melanoma that develops in the nail is easily mistaken for bruising, fungal infection or benign pigmentation, which can delay evaluation. Image-based tools might one day help flag nails that deserve earlier professional attention. This project explores whether a simple, interpretable machine-learning approach can separate melanoma-labelled from non-melanoma-labelled nail photographs. {% endcall %} {% call block('Objectives') %}
  • Build an end-to-end pipeline: dataset audit, preprocessing, feature extraction, training, evaluation, deployment.
  • Classify nail images as melanoma or non-melanoma using K-Nearest Neighbors.
  • Evaluate honestly with accuracy, precision, recall, specificity, F1 and a confusion matrix on a held-out test set.
  • Provide a simple web interface for uploading an image and viewing the processing steps and prediction.
{% endcall %} {% call block('Technologies used') %} Python · Flask · scikit-learn (KNN, StandardScaler) · scikit-image (GLCM) · OpenCV · Pillow · NumPy · Pandas · Matplotlib · Seaborn · Joblib · HTML, CSS, JavaScript, Bootstrap 5. {% endcall %} {% call block('Methodology') %}
  1. Dataset audit: count images per class; detect unreadable files and duplicates.
  2. Preprocessing: resize to 224 × 224, bilateral noise reduction, CLAHE contrast enhancement, heuristic nail-region segmentation.
  3. Features: RGB mean/std, colour histograms, HSV saturation/value statistics; GLCM contrast, correlation, energy, homogeneity and entropy; nail area, perimeter, aspect ratio, solidity, circularity and edge descriptors.
  4. Scaling: StandardScaler fitted on the training split only.
  5. Split: 70 / 15 / 15 train / validation / test, stratified, grouped by subject when subject IDs are supplied.
  6. Model selection: K, distance metric and vote weighting chosen on the validation set.
  7. Evaluation: the selected model is evaluated once on the test set.
{% endcall %}
{% call block('Advantages') %}
  • Simple and easy to explain: predictions come from similar labelled examples.
  • No heavy training stage; fast to experiment with.
  • Hand-crafted features are interpretable and run on ordinary computers.
{% endcall %}
{% call block('Limitations') %}
  • Not clinically validated; not a diagnostic tool.
  • Quality depends entirely on the size, balance and labelling of the training dataset.
  • Photos vary in lighting, skin tone, camera and background, which can mislead hand-crafted features.
  • Nail segmentation is a simple heuristic and can fail.
  • KNN probabilities are neighbour vote shares, not calibrated risks.
  • Pigmented nail changes need clinical examination and biopsy, which images cannot replace.
{% endcall %}
{% call block('Future enhancements') %}
  • Larger, multi-centre, clinically verified datasets with diverse skin tones.
  • Learned nail segmentation and deep-learning feature extractors compared against the KNN baseline.
  • Probability calibration, confidence intervals and external validation.
  • Dermoscopy images and patient-level metadata; clinician-in-the-loop review.
{% endcall %}
